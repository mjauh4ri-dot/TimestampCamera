# Timestamp Camera untuk iPhone

Web app/PWA kamera dengan timestamp tanggal, jam, detik, GPS, watermark, kamera depan/belakang, dan hasil foto dengan timestamp permanen.

## Menjalankan di iPhone
1. Upload file ke GitHub Pages atau hosting HTTPS.
2. Buka alamat HTTPS tersebut di Safari.
3. Tekan **Buka Kamera** dan izinkan Camera + Location.
4. Safari → Share → **Add to Home Screen**.
5. Jalankan dari ikon di Home Screen.

Kamera Safari memerlukan HTTPS. Ini adalah versi web/PWA; versi native iOS dapat dibuat kemudian jika ingin integrasi Photos, flash, zoom, dan kontrol kamera yang lebih lengkap.
